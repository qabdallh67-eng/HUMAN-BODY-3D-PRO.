# QUREO AI Assistant

Android starter project built with Kotlin.

## Current features
- Arabic Android interface.
- User-controlled Accessibility settings shortcut.
- Reads visible text from the active window and displays it in the app.

## Current limitations
This is an initial starter, not a finished AI product. It does not yet include an AI model or image OCR. It does not automatically click, submit answers, or complete graded assessments. It is intended for learning and practice support.

## Build
GitHub Actions builds a debug APK on every push to main and publishes it as a downloadable workflow artifact and GitHub Release asset.
